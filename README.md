# Microservice: UNIVERSITYVALIDATOR

Este proyecto implementa un **microservicio** para validar información universitaria, desarrollado con **FastAPI** y **PostgreSQL**. Permite registrar estudiantes, validar sus datos y exponer APIs REST para integrarse con otras aplicaciones o servicios.

---

## Tecnologías

- **Backend:** Python 3.12, FastAPI
- **Base de datos:** PostgreSQL
- **ORM:** SQLAlchemy
- **Servidor ASGI:** Uvicorn
- **Documentación automática de API:** Swagger / ReDoc (integrado en FastAPI)
- **Gestión de dependencias:** Poetry o pip + virtualenv

---

## Características principales

- Registro de estudiantes con validación de datos.
- Consulta de información de estudiantes por cédula o ID.
- Manejo de errores y validaciones robustas.
- Exposición de endpoints REST para integración con otros servicios.
